# Skills v3.3 · 风格选择、连接询问与分步编导

用户确认的需求：Q版可选；开始制作时询问API地址和Key；提示词与流程应让能力较弱的模型也更容易执行完整工作。本版直接实现，不增加方案确认或样图风格确认节点。

## 实现

1. 缺项询问：首次风格未定询问Q版／非Q版，同时补API地址、精确模型名和Key配置。已明确选择沿用，Key不重复索取；配置仅保存环境变量名。本次升级和离线验证不使用用户Key。
2. 风格贯穿：`style.mode`为chibi／standard／custom，预设约三头身与自然人体比例。修正旧代码末尾硬编码chibi的冲突；历史未声明mode的计划保持中性比例约束。切风格要重新准备一致的人物参考。
3. 小批编导：工作卡把输入、事实表、节奏、分镜、参考、试制、审图、交付逐步拆开。给出可直接执行的阶段任务提示，保存文件与恢复条件；不是一次性让模型填完整大计划。
4. 离线工具：`v3 init`创建待核验项目，`v3 styles`查看预设，`v3 compile`顺序合并多个小批分镜并补全ID、绑定、单视角人物参考、版式和文字区。保留完整v3入口处理复杂构图。简化入口限制单格人物与文字负载，超出时拆镜头或显式用完整入口。
5. 原有底线：人物参考必须实际入参且审阅；按当前服务资料选择协议、超时与频控；图片返回不代表验收。保留100张规划、实际画幅重排、缓存续作、六项SHA审查和严格导出。

## 验证范围

两种预设分别跑原创3页离线编译、参考与正文提示生成、排版和MOCK打包。检查原文锚点、实际参考绑定、版本依赖、错误说话者／张数／文字负载拦截，以及多文件合并顺序。初始化档案保持未核验并拒绝明文Key参数，不允许未经研究直接生图。2026-10-21完整测试50项通过，Skill结构校验通过；本机默认临时目录的沙箱替换限制由测试改用工作区临时目录解决。

本版没有新增付费API调用；离线测试不能证明某个较弱模型的实际画质或自主工作成功率，也没有对外部模型做能力评测。目标是降低漏项与格式错误，不用自动通过代替看图。
