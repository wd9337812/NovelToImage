# Skills v3.5：可选末张行动号召

用户要求：制作前让用户选择最后一张是否需要行动号召，以适配其发布渠道。此版本支持选择，不声称验证了任何平台的降推规则。

## 已实现

- 收集输入时与风格、API等缺项合并询问“需要／不要”；本任务已有明确选择就沿用。不因只修改技能或离线测试索取Key、风格或CTA偏好。
- 顶层`cta.enabled`保存布尔值；未回答的初始化草稿为`null`，不将沉默当默认选择。`v3 init --final-cta include/omit`显式配置，省略参数则待询问。新编译产物标记`authoring_version:"3.5"`，不能缺少CTA选择。
- 开启时仅最后一张有认可、明确标记的CTA；关闭时拒绝全套所有强CTA标记和keyword引导，末张保留有原文依据的剧情行动与悬念，不加空白结束页、额外导流页或隐蔽号召。正常故事中的搜索等行为不应误删。
- 生成提示按页面和选择约束引导内容，支持完整连字页与无字画稿路线；不自动更换模型、参考或限额。
- 关闭时继续保持用户要求的张数和有效阅读铺垫，阅读报告统计整套正文，首个CTA前时长为null，不发缺少CTA的警告。开启时沿用CTA前阅读估算，估计均不是实际留存数据。
- 新任务逐页审查增加CTA选择核对、布尔值和具体观察；缺少记录或与当前选择不符，严格导出拒绝。字段只检查已标记的CTA，旁白／画稿中漏标或模型生成的引导仍必须实际读图识别。
- 旧分镜未声明CTA时保留旧口径，不自动推断偏好、改原图或调用生图服务。保留v3.4首张、前三张专项审查、强制人物参考及频控要求；关闭CTA不代表可以交付短试样。
