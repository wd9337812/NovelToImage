# 阅读时长与行动召唤

适用于社媒推广节选。先让读者理解人物、看见行动代价、获得一次有原文依据的情节回报，再在下一处悬念出现时放强CTA。页数多不等于投入高；重复画面、同义旁白和无信息翻页不能计作有效铺垫。

没有用户指定时，将首个强CTA前约90–150秒作为可调整的编辑目标，优先规划18–24张；这是本Skill的起始假设，不是平台规则、实测留存或佣金保证。短原文、用户指定张数、渠道当前上传上限优先，不为达到数字编戏或拆成空洞的单句页。默认不因“不足18张”拒绝短篇。发布渠道上限需查当前官方说明，无法核实时交付连续编号图片并说明需在发布时确认，不能编造统一上限。

逐页填写`reader.known/new/open`，说明本页新增的行动、线索、人物关系或情绪变化。每3–5页检查是否有一次具体推进；封面引出矛盾，正文至少形成一次小闭环，最终保留下一层未解问题。不能把“继续读”放在几页之后就当作充分铺垫，也不能凭空增加小说未发生的反转。

分镜可提供：

```json
"pacing": {
  "target_seconds": [90, 150],
  "characters_per_second": 7.5,
  "seconds_per_panel": 2,
  "page_turn_seconds": 0.5,
  "rationale": "根据正文长度、对话与镜头密度安排，非实际观看数据"
}
```

执行`v3 pacing --plan plan.json --out pacing-report.json`。每页按`max(可见正文字数/阅读速度, 格数×看格时间)+翻页时间`估计，避免把同时看图读字的耗时机械相加。空白不计字；关键词CTA不计正文；检测到`keyword`或页面`strong_cta:true`时，首个CTA前时长保守地排除整张CTA页。若强CTA写在普通旁白里，也应显式标记`strong_cta`，不能借文字类型逃过估计。重复可见文字仍会被计数，必须人工剔除灌水，不能只靠公式验收。

90–150秒不是硬门槛。低于目标时优先补足已有原文的因果、人物选择、行动后果与关键反应；高于目标时删重复，或依渠道上限拆成各自有铺垫与悬念的连续篇章。调整速度参数需有具体说明，不可只为了让报告变绿而调参。允许用户给出更短或更长偏好。报告随制作包交付，明确区分估算与实际观看时长。

若参考其他作品，记录确实观察到的总张数、每页文字/格数、CTA出现位置；网页不可读或张数未知时写未知，不能把猜测当成竞品统计。上线后只有用户提供真实数据时，才据完读率、逐页退出位置与转化迭代目标。
