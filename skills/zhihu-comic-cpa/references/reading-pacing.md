# 阅读时长与行动召唤

适用于社媒推广节选。先让读者理解人物、看见行动代价、获得一次有原文依据的情节回报，再在下一处悬念出现时放强CTA。页数多不等于投入高；重复画面、同义旁白和无信息翻页不能计作有效铺垫。

本Skill的长篇推广默认60–100张，正文足够时优先100张。用户2026-10-21明确纠正20张不够，要求60–100张；浏览器实际核实其三个案例均100张。因此不再沿用18–24张或一两分钟作为长图集默认。短原文和用户指定数量优先，不为数字编戏。若原文不足，说明可支持的范围；不得把20张试样改名成100张完整版。渠道当前上传上限需另查官方说明；三个已发表案例为100张不等于所有账号、平台和发布入口都支持100张。

长集可先以首个强CTA前6–20分钟作为编辑目标，再按最终文字与格数算出本集估计，允许用户给出其他目标。这是工作流偏好与编辑估计，不是平台规则、实际观看数据或佣金保证。阅读时间长本身不保证用户投入，仍需持续给具体信息与情节回报。

逐页填写`reader.known/new/open`，说明本页新增的行动、线索、人物关系或情绪变化。每8–12张检查是否有一次具体推进或回报，多个相连的小闭环构成长集；开头引矛盾，中段展开动机、选择与代价，最后在下一层未解问题处放强CTA。分格仍逐页按剧情安排，不能把100张机械做成同款上下两格。不能凭空增加小说未发生的反转。

分镜可提供：

```json
"pacing": {
  "target_seconds": [360, 1200],
  "target_page_count": [60, 100],
  "enforce_page_range": true,
  "characters_per_second": 7.5,
  "seconds_per_panel": 2,
  "page_turn_seconds": 0.5,
  "rationale": "根据正文长度、对话与镜头密度安排，非实际观看数据"
}
```

执行`v3 pacing --plan plan.json --out pacing-report.json`。每页按`max(可见正文字数/阅读速度, 格数×看格时间)+翻页时间`估计，避免把同时看图读字的耗时机械相加。空白不计字；关键词CTA不计正文；检测到`keyword`或页面`strong_cta:true`时，首个CTA前时长保守地排除整张CTA页。若强CTA写在普通旁白里，也应显式标记`strong_cta`，不能借文字类型逃过估计。重复可见文字仍会被计数，必须人工剔除灌水，不能只靠公式验收。

6–20分钟不是硬门槛。低于目标时优先补足已有原文的因果、人物选择、行动后果与关键反应；高于目标时删重复，或依渠道上限拆成各自有铺垫与悬念的连续篇章。用户明确数量时以`enforce_page_range`在生图和导出前拦截缩水计划；只处理选定页仍保留完整计划，部分进度不得标完整。调整速度参数需有具体说明，不可为了报告“通过”调参。报告随制作包交付，明确区分估算与实际观看时长。

若参考其他作品，记录确实观察到的总张数、每页文字/格数、CTA出现位置；网页不可读或张数未知时写未知，不能把猜测当成竞品统计。上线后只有用户提供真实数据时，才据完读率、逐页退出位置与转化迭代目标。
